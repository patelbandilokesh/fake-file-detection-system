# Fake File Detection System

A Python and MySQL based Fake File Detection System developed using Flask framework.

## Features
- User Registration & Login
- Admin Panel
- Fake File Detection
- File Upload System
- MySQL Database Integration
- Password Recovery
- User Activity Monitoring

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- MySQL
